GameLauncher

一款简洁、高效的游戏启动器

本地存储 · 无需联网 · 磨砂玻璃 UI · 私密模式
为你的本地游戏库提供最纯粹的整理方式。

Download → View on GitHub

01 Features

  • [ + ]

    游戏管理

    添加 · 编辑 · 删除本地游戏，GID 唯一标识符支持跨数据库识别。

  • [ + ]

    标签与收藏

    自定义标签分类，收藏夹快速访问喜爱的游戏。

  • [ + ]

    私密模式

    键盘序列密码保护，隐藏私密游戏与设置入口。

  • [ + ]

    磨砂玻璃 UI

    云雾磨砂玻璃设计语言，深色 / 浅色主题完美适配。

  • [ + ]

    数据导入导出

    .gldata 备份文件一键迁移，含私密模式数据。

  • [ + ]

    托盘与统计

    游戏启动时缩入托盘，记录启动次数与游戏时长。

02 Stack

.NET 8.0 WinUI 3 Windows App SDK 1.8 SQLite Windows 10 1809+

03 Install

  1. 01

    安装 Windows App SDK 1.8 运行时

    windowsappruntimeinstall-x64.exe
  2. 02

    从 GitHub Releases 下载并解压发行包

    GameLauncher_v3.4.3_Windows_x64.zip
  3. 03

    双击运行 GameLauncher.exe 启动程序
