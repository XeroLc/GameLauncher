GameLauncher

一款简洁、高效的游戏启动器

本地优先 · 增量云同步 · 磨砂玻璃 UI · 私密模式
为你的本地游戏库提供最纯粹的整理方式。

Download → View on GitHub

01 Features

  • [ + ]

    游戏管理

    添加 · 编辑 · 删除本地游戏，GID 唯一标识符支持跨数据库识别。

  • [ + ]

    标签与收藏

    自定义标签分类，收藏夹快速访问喜爱的游戏。

  • [ + ]

    私密模式

    键盘序列密码保护，隐藏私密游戏与设置入口。

  • [ + ]

    磨砂玻璃 UI

    云雾磨砂玻璃设计语言，深色 / 浅色主题完美适配。

  • [ + ]

    增量云同步

    基于同步清单只传输变化文件，支持双向 / 仅上传 / 仅下载三种模式。

  • [ + ]

    Cloudflare R2

    本地同步文件夹与 S3 兼容对象存储双后端，可定时自动同步。

  • [ + ]

    数据导入导出

    .gldata 备份文件一键迁移，含私密模式数据。

  • [ + ]

    托盘与统计

    游戏启动时缩入托盘，记录启动次数与游戏时长。

02 Cloud Sync

GameLauncher 3.5 新增增量云同步：游戏数据库与图片可以安全地备份到云端， 或在多台设备之间保持一致。通过本地同步清单，每次只传输真正变化的文件， 上千乃至上万个文件的同步也能保持轻量。

双后端

本地同步文件夹（OneDrive / Dropbox / Syncthing 等）或 Cloudflare R2 对象存储。

增量传输

按大小、修改时间与 ETag 判定变化，只上传 / 下载发生变更的文件。

安全删除

同步导致的删除先进入本地或远端回收站，密钥使用 Windows DPAPI 加密保存。
