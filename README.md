# GameLauncher

一款简洁、高效的游戏启动器，帮助您轻松管理本地游戏。

![Version](https://img.shields.io/badge/version-1.8.1-blue)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)
![.NET](https://img.shields.io/badge/.NET-8.0-purple)

## 功能特性

- 🎮 **游戏管理** - 轻松添加、编辑、删除本地游戏
- 🏷️ **标签系统** - 为游戏添加标签，支持标签筛选和分类管理
- 🔍 **快速搜索** - 实时搜索，可通过游戏名称、描述或标签快速找到目标游戏
- 📊 **游戏统计** - 记录游戏启动次数和游戏时长
- 🖼️ **游戏预览** - 支持多张游戏预览图，点击可放大查看
- 🎯 **批量操作** - 支持批量删除游戏
- 💾 **本地存储** - 所有数据本地存储，无需联网
- 🎨 **现代界面** - 基于 WinUI 3 打造的现代化用户界面
- 📋 **托盘最小化** - 游戏启动时自动最小化到系统托盘，游戏结束后自动恢复窗口
 
## 系统要求

- Windows 10 1809 (10.0.17763.0) 或更高版本
- Windows 11
- 64 位系统 (x64)

## 安装步骤

### 1. 安装 Windows App SDK 运行时

GameLauncher 使用 WinUI 3 框架，需要先安装 Windows App SDK 运行时。

**下载地址：** https://aka.ms/windowsappsdk/1.8/windowsappruntimeinstall-x64.exe

安装步骤：
1. 下载 `windowsappruntimeinstall-x64.exe`
2. 双击运行安装程序
3. 按照提示完成安装
4. 安装完成后重启计算机（推荐）

### 2. 运行 GameLauncher

1. 解压 `GameLauncher_v1.7_Windows_x64.zip`
2. 双击 `GameLauncher.exe` 启动程序
3. （可选）创建快捷方式到桌面

## 使用说明

### 添加游戏

1. 点击右上角的「添加游戏」按钮
2. 填写游戏信息：
   - 游戏名称
   - 游戏路径（必填）
   - 游戏图标（可选）
   - 游戏描述（可选）
   - 游戏预览图（可选，支持多张）
3. 点击「保存」完成添加

### 启动游戏

1. 找到目标游戏卡片
2. 点击「启动」按钮即可启动游戏

### 编辑游戏

1. 找到目标游戏卡片
2. 点击「编辑」按钮
3. 修改游戏信息后保存

### 删除游戏

**单个删除：**
1. 找到目标游戏卡片
2. 点击「删除」按钮

**批量删除：**
1. 点击「批量操作」按钮进入选择模式
2. 勾选需要删除的游戏
3. 点击「删除选中」按钮

### 搜索游戏

在搜索框中输入游戏名称，列表会实时过滤显示匹配的游戏。

### 查看游戏详情

点击游戏卡片即可查看详细信息，包括：
- 游戏描述
- 启动次数
- 游戏时长
- 添加时间
- 游戏预览图（点击可放大查看）

## 技术支持

### 常见问题

**Q: 程序无法启动怎么办？**

A: 请检查以下几点：
1. 是否已安装 Windows App SDK 1.8
2. Windows 版本是否满足要求（Windows 10 1809 或更高）
3. 是否有足够的系统权限

**Q: 游戏无法启动怎么办？**

A: 请检查：
1. 游戏路径是否正确
2. 游戏文件是否完整
3. 是否有足够的系统权限运行该游戏

**Q: 数据存储在哪里？**

A: 所有游戏数据存储在本地数据库中，位于程序目录下的 Data 文件夹。
