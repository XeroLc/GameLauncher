# GameLauncher

一款简洁、高效的游戏启动器，帮助您轻松管理本地游戏。

![Version](https://img.shields.io/badge/version-3.5.1-blue)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)
![.NET](https://img.shields.io/badge/.NET-8.0-purple)

## 功能特性

- 🎮 **游戏管理** - 轻松添加、编辑、删除本地游戏
- 🆔 **GID 唯一标识符** - 每个游戏拥有独立 GID，支持跨数据库唯一识别
- 📦 **GMD 文件管理** - 统一 GID 命名规范，支持一键清理旧格式文件
- 🏷️ **标签系统** - 为游戏添加标签，支持标签筛选和分类管理
- ⭐ **收藏夹功能** - 收藏喜爱的游戏，快速访问收藏列表
- 📁 **资源文件管理** - GMD 导入自动创建专用资源文件夹，图标/预览图统一存储
- 🔍 **快速搜索** - 实时搜索，可通过游戏名称、描述或标签快速找到目标游戏
- 📊 **游戏统计** - 记录游戏启动次数和游戏时长
- 🖼️ **游戏预览** - 支持多张游戏预览图，点击可放大查看
- 🎯 **批量操作** - 支持批量删除游戏
- 💾 **本地存储** - 所有数据本地存储，无需联网
- 🎨 **磨砂玻璃 UI** - 云雾磨砂玻璃设计语言，现代美观
- 🔄 **自动更新检查** - 启动时自动检查 GitHub 最新版本，支持手动检查
- ⚡ **依赖注入架构** - 服务通过 DI 容器管理，线程安全，可测试性强
- 📋 **托盘最小化** - 游戏启动时自动最小化到系统托盘，游戏结束后自动恢复窗口
- 🌙 **主题切换** - 支持深色/浅色主题切换
- 📈 **游戏排序** - 支持多种排序方式（名称、启动次数、时长等）
- ✏️ **快速编辑** - 在游戏详情页面直接编辑游戏信息，无需返回列表
- 💾 **数据导入导出** - 支持 .gldata 备份文件导出和导入游戏数据
- ☁️ **增量云同步** - 支持本地同步文件夹与 Cloudflare R2 两种后端，增量同步游戏数据库与图片
- 🔧 **调试模式** - 内置调试面板，显示数据库统计和操作日志
- 🔒 **私密模式** - 键盘序列密码保护，隐藏私密游戏和设置
 
## 系统要求

- Windows 10 1809 (10.0.17763.0) 或更高版本
- Windows 11
- 支持 x86 / x64 / ARM64 架构

## 安装步骤

### 1. 安装 Windows App SDK 运行时

GameLauncher 使用 WinUI 3 框架，需要先安装 Windows App SDK 运行时。

**下载地址（按架构选择）：**
- x64：https://aka.ms/windowsappsdk/1.8/windowsappruntimeinstall-x64.exe
- x86：https://aka.ms/windowsappsdk/1.8/windowsappruntimeinstall-x86.exe
- ARM64：https://aka.ms/windowsappsdk/1.8/windowsappruntimeinstall-arm64.exe

安装步骤：
1. 下载对应架构的 `windowsappruntimeinstall-*.exe`
2. 双击运行安装程序
3. 按照提示完成安装
4. 安装完成后重启计算机（推荐）

### 2. 运行 GameLauncher

1. 解压对应架构的 `GameLauncher_v3.5.1_Windows_<x64|x86|arm64>.zip`
2. 双击 `GameLauncher.exe` 启动程序
3. （可选）创建快捷方式到桌面

## 使用说明

### 添加游戏

1. 点击右上角的「添加游戏」按钮
2. 填写游戏信息：
   - 游戏名称
   - 游戏路径（必填）
   - 游戏图标（可选）
   - 游戏描述（可选）
   - 游戏预览图（可选，支持多张）
3. 点击「保存」完成添加

### 启动游戏

1. 找到目标游戏卡片
2. 点击「启动」按钮即可启动游戏

### 编辑游戏

1. 找到目标游戏卡片
2. 点击「编辑」按钮
3. 修改游戏信息后保存

### 删除游戏

**单个删除：**
1. 找到目标游戏卡片
2. 点击「删除」按钮

**批量删除：**
1. 点击「批量操作」按钮进入选择模式
2. 勾选需要删除的游戏
3. 点击「删除选中」按钮

### 搜索游戏

在搜索框中输入游戏名称，列表会实时过滤显示匹配的游戏。

### 查看游戏详情

点击游戏卡片即可查看详细信息，包括：
- 游戏描述
- 启动次数
- 游戏时长
- 添加时间
- 游戏预览图（点击可放大查看）

### 私密模式

1. 在设置中设置键盘序列密码（默认：↑↑↓↓←←→→aabb）
2. 通过「管理私密游戏」按钮选择要隐藏的游戏
3. 在主界面按下键盘序列密码进入/退出私密模式
4. 私密模式下仅显示标记为私密的游戏，设置界面隐藏相关选项

> ⚠️ **忘记密码？** 如果遗忘了私密模式的键盘序列密码，可将 [AdditionalResources/reset_private_password.glkey](./AdditionalResources/reset_private_password.glkey) 文件拖入主窗口来重置密码。

### 增量云同步

在设置页面的「增量云同步」区域中：

> 📖 完整配置步骤（含 Cloudflare R2 后台准备、字段对照和故障排查）见 [云同步配置指南](docs/云同步配置指南.md)。

1. 开启「启用云同步」
2. 选择同步方式：
   - **本地同步文件夹**：选择一个由 OneDrive / Dropbox / Syncthing 等工具同步的文件夹，游戏数据会先同步到该文件夹，再由对应工具上传到云端
   - **Cloudflare R2**：填写 R2 Endpoint、Bucket、Access Key ID、Secret Access Key，程序通过 S3 兼容 API 直接同步到 R2
3. 选择同步方向：双向同步（默认）/ 仅上传备份 / 仅下载恢复
4. 选择自动同步间隔，或保持「手动」通过「立即同步」按钮执行

同步范围：`%LOCALAPPDATA%\GameLauncher` 下的游戏数据库与游戏图片。设置文件（含 R2 密钥）、崩溃日志和 SQLite WAL 文件不会同步；R2 密钥使用 Windows DPAPI 加密保存在本机。

> 🛡️ **删除安全**：同步导致的删除不会直接丢失文件——本地删除先进 `.sync/trash`，远端删除先进 `.trash`（文件夹）或 `_trash/`（R2），需要时可手动恢复。

## 技术支持

### 常见问题

**Q: 程序无法启动怎么办？**

A: 请检查以下几点：
1. 是否已安装 Windows App SDK 1.8
2. Windows 版本是否满足要求（Windows 10 1809 或更高）
3. 是否有足够的系统权限

**Q: 游戏无法启动怎么办？**

A: 请检查：
1. 游戏路径是否正确
2. 游戏文件是否完整
3. 是否有足够的系统权限运行该游戏

**Q: 数据存储在哪里？**

A: 所有游戏数据存储在本地数据库中，位于程序目录下的 Data 文件夹。
